# MyFastReader

## Features

- Opens FB2, EPUB, and ZIP archives containing books
- Table of contents with per-chapter reading progress
- Bookmarks and reading statistics (characters, time, actual speed)
- Speed-reading modes:
  - RSVP with adjustable block size and speed
  - Highlighting: ORP, ORP+, Bionic, Creep
  - Trail of recent chunks, punctuation pauses
- Gradient scroll mode
- Copy chapter text to clipboard

---

## Возможности

- Открытие FB2, EPUB и ZIP-архивов с книгами
- Оглавление с прогрессом чтения по главам
- Закладки и статистика (символы, время, фактическая скорость)
- Режимы скорочтения:
  - RSVP с настройкой размера блока и скорости
  - Выделение: ORP, ORP+, Bionic, Creep
  - Трейл прочитанного, паузы на пунктуации
- Режим градиентной прокрутки
- Копирование текста главы в буфер обмена
